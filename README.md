Kaggle Data Warehouse mit PostgreSQL

Entwicklung eines lokalen Data-Warehouse-Projekts mit PostgreSQL und Docker. Mehrere Kaggle-Datensätze wurden über Python-basierte ETL-Prozesse importiert, transformiert und in relationalen Tabellen gespeichert. Die Daten wurden anschließend mit SQL analysiert und über pgAdmin verwaltet.

Technologien: PostgreSQL, Docker, Python, Pandas, SQL, Jupyter Notebook, pgAdmin.

Für eine Stelle als Data Engineer, Data Analyst, BI Analyst oder AI-/ML-Engineer wirkt die zweite Variante am stärksten. Sie zeigt Praxis mit ETL, Datenbanken und Datenimport aus realen Quellen.
